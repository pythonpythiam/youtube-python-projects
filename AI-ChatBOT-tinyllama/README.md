# Python AI Chatbot (TinyLlama)

🤖 **Build your own AI Chatbot using Python and TinyLlama – 100% Free!**

This project allows you to run a **local AI chatbot** using Python and TinyLlama.  
No API keys, no billing, and no usage limits. Everything runs **locally on your computer**.

---

## 🚀 Features

- Chat with a local AI chatbot
- Easy to set up (just a few lines of Python)
- 100% free, works offline
- Compatible with TinyLlama or other local LLM models

---

## 📝 Requirements

- Python 3.8+
- `requests` library
- TinyLlama or other local LLM server running on your machine
