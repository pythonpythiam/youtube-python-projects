## ⚙️ Requirements

Install required libraries:

pip install opencv-python cvlib tensorflow

▶️ How to Use
Download or clone this repository
Add your video file as people.mp4 in the project folder
Make sure the file name matches in the code

▶️ Execution

Run the script:

python person_detection.py

📊 Output
Detects people in the video
Draws bounding boxes
Displays live count like: People: 5
