# ⌨️ Python Keyboard Listener

A simple Python script that detects and prints keyboard key presses in real-time.

## 🚀 Features

- Detects every key press instantly
- Displays key names in the terminal
- Stops execution when `ESC` is pressed
- Lightweight and easy to use

---

## 📦 Requirements

- Python 3.x
- keyboard library

Install the required library:

```bash
pip install keyboard
