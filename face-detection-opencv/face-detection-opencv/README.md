⚙️ Requirements

Make sure Python is installed on your system.

Install the required package:

pip install -r requirements.txt

This installs the OpenCV library used for face detection.

▶️ Run the Program

Run the following command in the project folder:

python face_detect_from_image.py

🖼️ How It Works

The script loads the image face.PNG from the current folder.

The program detects faces using OpenCV's Haar Cascade model.

A green rectangle is drawn around detected faces.

The output image is displayed in a window.

❌ Exit the Program

Press ESC to close the image window.

📌 Notes

• Ensure the image file name is exactly face.PNG
• The image must be placed in the same folder as the Python script.
